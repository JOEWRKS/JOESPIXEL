# JOESPIXEL

원본 이미지를 픽셀 아트로 만드는 Codex 스킬입니다.

이 브랜치는 8단계 개정판입니다. 비픽셀 원안을 만든 뒤 선·면을 함께 배치합니다. 기존 설치본은 자동으로 교체되지 않습니다.

## 설치

Codex에 아래 문장을 보내세요.

```text
https://github.com/JOEWRKS/JOESPIXEL 의 codex/single-grid-revision-20261119 브랜치 스킬을 설치하고 실행 준비까지 해줘.
```

## 사용

설치 후 원본 이미지를 첨부하고 요청하세요.

```text
$joespixel 이 이미지로 픽셀 아트 만들어줘.
```
