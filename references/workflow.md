# 8단계 제작 계약 — 2.26.0-eight-stage.7-claude

신규 제작은 아래 순서를 따른다. 단계 수와 검사 수치는 시각 품질을 보증하지 않는다. 필수 형태가 손상되면 최초 손실 단계로 돌아간다. 사용자 지시가 형태보다 우선하며, 지정 격자에서 불가능한 부분은 근거와 함께 따로 보고한다.

| 단계 | 입력 → 산출물 | 통과 조건 |
| --- | --- | --- |
| 1. 요청·원본 분석 | 실제 원본 → 조건·필수/생략 목록 | 비율·자세·표정·물체 관계와 실패 조건이 명시됨 |
| 2. 비픽셀 원안 | 원본·조건 → 매끈한 원안 | 원본과 눈·입·가림·재질을 직접 대조함 |
| 3. 재질·경계 배정 | 같은 원안 → 관찰표·소속 지도 | 면 소속과 외곽/접촉/장식선, 보호 특징을 구별함 |
| 4. 격자 선정 | 원안·역할 → 실제 후보 비교 | 필수 선·면·틈이 공존함; 지정 크기는 임의 변경하지 않음 |
| 5. 선·면 공동 배치 | 소속·격자 → 실행된 배치 기록 | 필수 선과 연결 면·끝·간격을 함께 배정하고 충돌을 해결함 |
| 6. 격자 초안 | 확정 배정 → native PNG | 배정이 렌더링에 반영되고 눈·입 등 선행 소유권을 침범하지 않음 |
| 7. 시각 검수 | 원안·초안 → 부위별 비교 판정 | 전체와 확대에서 형태가 실제 개선되고 다른 부위가 퇴화하지 않음 |
| 8. 확정·저장 | 잠긴 초안 → 저장 PNG·영수증 | 복사 전후 PNG를 다시 읽어 배열·격자·팔레트·실제 선을 확인함 |

## 1–2. 분석과 원안

캐릭터화·치비화·비율 변경을 요청 없이 추가하지 않는다. 캐릭터 원본과 새 원안의 역할은 별개다. 원안부터 잘못된 물체 소속이나 가림은 변환선으로 덮지 않는다. 가려진 팔은 보이는 양쪽 구간과 가리는 물체, 경계가 뒤로 사라지는 위치를 확인한다.

원안은 illustration이다. 가짜 픽셀을 먼저 생성한 뒤 다시 격자에 맞추지 않는다. 정확한 native 격자 파일의 보존·정수 확대는 이 재변환 경로와 구별한다.

## 3. 재질·경계 관찰

같은 RGB라도 선·음영·채움 역할은 다르다. 피부와 머리의 비슷한 색, 눈과 앞머리의 겹침은 현재 원안의 좌표와 표본으로 구분한다. 관찰 사각형 전체를 눈이나 피부로 지정하지 않는다. 피부는 최대 3색이며 볼터치·반사·코 음영은 별도로 판단한다.

materialPlan은 원안/팔레트/격자/특징 정책에 해시로 묶인다. 관찰 지도는 실행 계획에서 컴파일하여 원안과 대조한다. 코드가 의미를 자동 인식한다고 주장하지 않는다. source roleWitnesses는 알려진 머리/피부 소속의 누락을 검출하지만 전체 형태 승인이 아니다.

## 4. 격자 수용력

사용자 지정이면 user-fixed로 그 크기를 실제 시험한다. 미지정이면 같은 원안·캔버스·점유율·팔레트에서 최소 두 크기를 비교한다. native, 정수 확대, 실제 선 마스크를 저장한다. 후보마다 전체 윤곽·1도트 폭·열린/닫힌 틈·필수 이목구비·원안 충실도를 확인한다.

선만 남고 면이 없어지는 후보는 통과가 아니다. 전역 해상도 부족, 잘못된 소속, 배치 충돌을 구별한다. 일부 미세 평행선의 수용력 부족을 전체 앞머리의 손상 원인으로 일반화하지 않는다.

## 5. 선·면 공동 배치

필수 선은 우선 배정하되 모든 검은 표본을 필수 선으로 승격하지 않는다. 외곽·물체 접촉·주요 가닥 경계와 장식/반사/미세 중복선을 구별한다. 생략 판단은 원안 관찰로 먼저 기록한다.

lineLayouts에는 원본 좌표의 영역, 경로와 연결 면을 기록한다. 각 면의 axis는 몸통에서 끝 방향의 관찰이며 목적지 픽셀이 아니다. 공용 배치기는 반 도트 이내 경로 후보와 인접 면을 함께 평가한다. 필수 면이 끊기거나 피부 틈이 지워지거나 보호 특징을 침범하거나 2×2 선 뭉침이 생기면 후보를 거부한다. 유효 후보가 없으면 실패를 기록하며 격자를 바꾸거나 원안에 없는 선을 만들지 않는다.

배치 결과는 선/채움 소유권으로 렌더러에 전달한다. 해당 영역의 기존 선을 교체하고, 나중의 선 복원이나 곡선 정리가 이를 덮지 못하게 한다. 영역 밖의 실제 모서리·접합·틈과 기존 규칙은 유지한다. surfaces와 lineLayouts의 중복 소유는 차단한다.

원본 관찰 경로가 필요한 작업은 그 사실을 결과에 밝힌다. 코드에 캐릭터 이름, 목적지 도트 좌표 또는 전용 보정 분기를 추가하지 않는다.

## 6. 렌더링

고정 격자에서 재질 제약과 특징 소유권을 유지하고 joint-source-band로 선·면을 합성한다. anchored-source-curve는 실제 모서리·접합·틈을 유지하는 후보만 사용한다. 기존 선과 새 선을 합친 저장 RGB에서 폭·누락·잔여 잉크·외부 노출·면 연결을 검사한다.

선 교체 범위와 물체의 점유 범위는 구별한다. 넓은 검은 재질이나 관절 음영은 geometry: fill로 유지한다. vacated 선 칸은 같은 쪽 재질로 채우며 다른 면이나 원본 RGB 재분류로 덮지 않는다. fill·눈·입 보호도 실제 선 검사에서 면제하지 않는다.

## 7. 직접 비교와 원인 단계 복귀

원본/원안·격자 초안·기존본을 같은 위치와 표시 배율로 비교한다. 전체, 실제 크기, 정수 확대를 모두 본다. 각 항목에 관찰 차이·기준·이유·증거를 따로 기록한다.

- 앞머리: 가닥 면의 연결·끝 방향·피부 틈·눈과의 관계.
- 눈: 각 눈 비율·기울기·시선·홍채 면·반사·상부 선의 접촉 관계.
- 피부/입: 기본 면·음영 소속·코의 밝음/음영·입 전체 곡선과 표정.
- 손/의상: 손가락 면·굽힘·틈·물체 접촉·가림 순서·정상 반사.
- 외곽선: 실제 폭·누락·계단 흐름·모서리·접합·외부 돌출.

변경 0은 보존 증거이며 개선 증거가 아니다. 시각 손상이 자동 검사와 충돌하면 시각 항목은 FAIL이다. 7단계는 그림을 편집하지 않는다. 원인을 2–6단계에서 수정하고 그 이후를 다시 실행한다.

## 8. 저장

prepare → 직접 검수 → lock → finalize → verify를 사용한다. lock은 원안과 배치 기록으로 재현해 검수 PNG와 비교한다. finalize는 잠긴 PNG 복사만 수행하고 8단계 저장 검수 기록을 남긴다. verify는 저장 파일·입력·코드·검수 기록의 결속과 실제 도트 배열을 다시 확인한다.

미실행·누락은 UNVERIFIED이며 잠금을 막는다. 필수 시각 결함이 남은 결과는 잠그지 않는다. 기술 통과·시각 판단·사용자 채택을 구분하여 보고한다.
