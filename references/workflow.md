# 7단계 제작 계약 — 2.24.0

현재 제작의 단일 절차다. 신규 제작은 아래 7단계와 고정 격자 실행만 지원한다.

## 1. 원본 분석·캐릭터화

실제 원본을 직접 사용해 자세·비율·인상·물체 관계를 유지하는 캐릭터화본을 만든다. 캔버스와 캐릭터 점유율, 고정 팔레트·재질 역할, 외곽선 적용 범위/색, 필수 형태와 생략 가능한 디테일, 사용할 변환 방식을 정한다. 픽셀 크기는 이 단계에서 최종 확정하지 않는다. 원본 인상에 필요한 최소 구조를 먼저 확인한다.

가려진 팔다리는 보이는 양쪽 구간, 가리는 전경 물체, 경계가 뒤로 사라지는 위치를 대응 부위에서 확인한다. 생성본에서 물체 소속이나 앞뒤 순서가 달라졌다면 검은 연결선·채움 면을 추가해 통과시키지 말고 원안을 수정한다.

눈은 원본의 각 눈 가로·세로 비율, 상부 좁아짐, 기울기, 양쪽 크기·위치 관계와 위쪽 획의 접촉/근접/분리를 대응 부위 이미지와 함께 기록한다. 명칭이 다른 역할을 반드시 떨어뜨릴 대상으로 취급하지 않는다. 이 기록을 캐릭터화·설계·격자 초안마다 원본과 직접 대조하며, 바뀐 중간 원안만 기준으로 삼지 않는다.

금지: 이전 성공 이미지 재사용을 새 생성으로 보고, 임의 치비화·포즈 변경, 아직 평가하지 않은 격자의 표현력을 이미 확보했다고 가정.

## 2. 픽셀 크기·외곽선 수용력 선정 — 제작 선행 필수 단계

**크기 선택의 최우선 조건은 필요한 전체 외곽선을 1논리 도트로 배치할 수 있고, 그 안팎의 형태가 살아남는가다. 굵게 보이는 정도나 평균 주기로 크기를 정하지 않는다.** 선만 그을 공간이 있고 피부·눈·틈이 사라지는 후보는 탈락이다. 선이 없는 작화도 이 단계에서는 전체 윤곽에 1도트를 배정할 표현 용량을 시험하되, 최종 선 유무는 확정한 스타일 정책을 따른다.

1. 같은 캐릭터화본·캔버스·점유율·팔레트·변환 방식으로 최소 두 개의 서로 다른 도트 크기를 비교한다. 고정 후보 개수가 탐색 종료 조건은 아니다. 더 작은 도트 = 더 많은 논리 칸 = 더 높은 표현 용량이다. 표시 확대만 바꾼 비교는 후보가 아니다.
2. 원본과 캐릭터화본에서 필요한 전체 외부 윤곽과 식별에 필요한 내부 접촉 경계를 목록으로 기록한다. 머리/장식/손끝/옷자락/소품까지 누락하지 않는다. 실제 원본에서 없는 선을 새로 만들라는 뜻은 아니다.
3. 각 격자에 윤곽과 인접 주요 색면을 시험 배치한다. 전신 native PNG, 정수 확대 PNG, 실제 선 배정 마스크를 저장한다. 이는 용량 시험이며 완성 픽셀 디자인이나 단순 축소 납품본이 아니다.
4. 저장본을 전체와 병목 부위에서 직접 검사한다. 필수 경계별로 **누락 없이 이어짐 / 1도트 폭 / 계단과 곡선 / 접합부 / 선 옆의 틈·색면 공간**을 따로 판단한다. 눈·코·입, 손의 잡는 덩어리와 물체 접촉이 함께 읽혀야 한다. 보호 영역이나 접합부를 검수 예외로 두지 않는다.
5. 모두 충족한 후보 중 원본 인상과 목표 픽셀 스타일에 적합한 것을 선택하고 이유와 다른 후보의 탈락 이유를 남긴다. 가장 굵은 도트·가장 많은 도트·가장 높은 종합점수의 자동 선택을 금지한다. 충돌이 남으면 후보를 더 검토한다. 가능한 후보가 없는데 크기를 강제 확정하지 않는다.
6. 선택한 native 가로/세로 칸 수, 한 도트 표시 크기, 캔버스, 원점/여백을 잠근다. 이후 단계에서 생성 모델이 다른 주기로 그렸다는 이유로 이 값을 바꾸지 않는다.

금지: 전체 평균 주기나 해시/색 검사만으로 적합 판정, 눈만 작은 격자, 2×2 도트로 외곽선 두껍게 만들기, 피부 면을 먹어 선 공간 확보, 틈을 닫거나 보이는 입을 지워 통과, 한 부위 성공으로 전신 승인, 원본 소품/가닥 삭제로 검수 목록 축소, 프롬프트 선언만으로 후보 시험 대체.

## 3. 선택된 격자용 설계 원안

새 캐릭터화본에서 선택 격자에 맞는 색면·선·필수 이목구비를 설계한다. 한 논리 도트보다 작은 입·눈 반사를 고해상도 선으로 그려놓고 변환 때 살아날 것이라 가정하지 않는다. 피부 밝음/기본/어두움 최대 3색, 고정 팔레트, 눈의 단색 역할 구분을 적용한다. 볼터치와 피부 음영은 구분한다. 손가락 굽힘은 가용 용량 안에서 음영으로 표현하고 소품 외형·닫힘을 반사보다 우선한다.

실측 주기와 실제 대표 선 폭을 각각 관찰해 선택 격자와의 차이를 확인한다. 실측은 진단이며 규격 변경 권한이 아니다. 생성 원안은 정확한 도트 배열이 아니다. 실제 격자 초안은 5단계에서 만들어지며, 원안의 선 폭과 달라진 부분을 별도로 비교한다. 필수 형태가 없거나 선택 격자에 필요한 면을 설계하지 못했으면 여기서 다시 만든다.

## 4. 재질·경계 배정 확정

4A 영역 구분: 눈 검색 창과 실제 눈 소스 다각형을 구분한다. 눈·피부·머리·접촉선의 담당 영역을 관찰한 후 구분 이미지를 확인한다.

피부 배정은 얼굴 안쪽뿐 아니라 눈 밑·코 주변·턱 끝까지 덮는지 소스 구분 이미지로 확인한다. 코 같은 보호 특징은 실제 형태만 제외하며 주변 피부까지 사각형으로 면제하지 않는다. 눈·입 배치도 원본 표본과 재질 배정이 함께 피부로 확인한 주변 면의 색을 이어받는다. 넓은 피부 영역만으로 속눈썹·흰자까지 피부색으로 바꾸거나, 확정 피부를 전역 팔레트로 되돌리지 않는다.

4B 경계 충돌 확인: 4A의 눈 형태를 모든 연산에 동일하게 전달한다. 눈 검색 창과 머리 선 영역이 겹치면 실제 눈 다각형 없이는 실행을 차단한다. 눈 옆 선의 소스 시작·끝·연결이 배정 전에 빠지지 않았는지 확인한다. 어느 한 검사가 미달이면 5단계로 넘어가지 않는다.

보이는 눈은 입력 계약의 `source-partitions`로 배정한다. 위쪽 속눈썹이 눈 소유 영역에서 빠지지 않아야 한다. 홍채 안의 어두운 색을 눈꺼풀로 배정하지 않고, 실제 소스 역할 구분 PNG에서 홍채·동공·흰자·반사를 확인한다. 같은 family의 여러 색은 격자 칸을 놓고 서로 경쟁시키지 않는다. 반사가 흰자와 원래 연결되어 있다면 그 연결 자체를 오류로 판단하지 않는다.

이미지를 새로 생성하거나 출력 도트를 고치는 단계가 아니다. 초안 위에서 재질 소속, 허용 색, 선/음영, 필수 특징의 역할을 확정하고 실행 가능한 `materialPlan`과 소스 구분 PNG를 저장한다.

- 재질: 관찰된 원본 다각형과 이름, 허용 고정 팔레트색 및 기본색. 피부는 최대 3색. 재질 영역의 중복은 해소 전 실행 금지.
- 어두운 연결 면: 관절·소매·옷 안쪽처럼 선색과 겹치는 채움은 `geometry: fill`로 구분한다. 원안에 면이 존재하는지 먼저 확인하며, 없는 해부학적 연결을 재질 배정으로 만들어내지 않는다.
- 경계: 확정한 외곽선/내부선 정책을 해시로 묶고, 재질 안에서 유지할 관찰 선 역할을 참조한다. 선과 어두운 음영 면을 혼동하지 않는다.
- 특징: 눈·코·입·소품 접촉 등 별도 역할 영역을 명시한다. 피부색 제한으로 지우지 않는다.
- 미수정 부분: 전체 부위 목록에 적용/기존 유지/없음을 기록한다. 유지 판단은 현재 원본과 기준본 근거가 있어야 하며 미확인을 유지로 처리하지 않는다.
- 검수: 코드가 실제 입력에서 만든 소스 구분 PNG를 원본과 대조한다. 영역이 머리/피부/장갑을 잘못 포함하면 여기서 수정한다. 단계 PASS 문구만 있고 실행 자료가 없으면 다음 단계 금지.

계획 파일과 원본 픽셀·팔레트·격자·경계 정책을 결속한다. 현재 공용 실행은 fixed-asset-grid/source-region-area를 지원하며 다른 경로는 계획 무시 대신 차단한다. 자동 의미 인식이 아니며 원본 관찰 입력이 필요하다.

## 5. 고정 격자 초안 작성

선 추출 → 실제 모서리·접합부 고정 → 둥근 구간의 흐름 정리 → 주 진행축 칸 중심의 단일 격자 배치 순서를 지킨다. 선 조각별 통과 칸 누적으로 가로 돌출을 만들지 않는다. 원본 선의 위치 범위 안에서 계단의 급격한 직각 전환을 줄이되, 모서리 기준칸·선과 배경의 연결 구조·인접 선과의 간격이 바뀌면 후보를 채택하지 않는다. 이동한 선의 안팎을 채움 배정에도 전달한다. 최종 저장 RGB에서 새 배경 구멍과 기존 닫힌 틈의 위치·면적 변화를 검사한다. 변경 없는 구간을 개선으로 보고하지 않는다. 곡선 배치·선 연결·채움 영역 검사 미실행은 통과할 수 없다.

정식 외곽선 실행은 `joint-source-band`를 사용한다. 4단계의 역할과 원본 RGB를 함께 읽어, 같은 역할의 양끝 사이에 실제 좁은 선 근거가 있는 분류 끊김을 추출 전에 연결한다. 서로 다른 역할·보호 특징·밝은 틈을 가로지르지 않는다. 재배치한 선이 주변 외부 채움도 결정한다. 저장 RGB에서 선언된 소스 선 영역의 색면이 배경으로 노출되면 차단한다. 선 없는 어두운 재질 윤곽과 캔버스 잘림은 별도 선 누락으로 계산하지 않는다. 선언 영역 밖 검사 범위를 기록한다. 실제 선·바깥쪽 검사 미실행/실패는 저장 통과를 차단하며 시각적 완전성을 대신하지 않는다.

연결 근거는 해당 누락 구간의 양쪽 접촉으로 판단한다. 닫힌 윤곽의 양끝이 다른 경로로 이미 연결됐다는 이유로 복구를 제외하지 않는다. 원본의 잉크→혼합색→면 전이가 확인된 1소스 픽셀 경계만 선에 귀속하며 반복 팽창하지 않는다. 확정한 좁은 선 단면 안의 임시 재질 추정은 빈자리 채움을 막을 수 없지만, 관찰된 채움 면과 특징 보호는 유지한다. 배치 검수와 별개로 비교 이미지도 native의 정수 배율을 사용한다.

선/채움 폭 분류는 접합점의 국소 최대 폭과 선 본체의 폭을 구분한다. 접합점 한 곳이 두껍다는 이유로 긴 선 전체를 채움으로 면제하지 않는다. 실제 넓은 재질 면의 명시적 소유권은 그대로 유지한다.

4단계의 배정표를 소비하여 하나의 격자에서 다음 책임을 순서대로 수행한다. 역할별 색 표본은 현재 원안에서 관찰한다.

| 처리 | 결정하는 것 | 뒤에서 변경할 수 없는 것 |
| --- | --- | --- |
| 재질 제약을 적용한 연결 색 면 분할 | 허용색, 실제 대비와 연결된 음영 면 | 픽셀별 RGB 재배정으로 면 정리를 취소하지 않음 |
| 면적·특징 배치 | 같은 격자의 색면, 실제 눈·입의 선과 채움 | 검색 사각형 전체를 특징으로 오인하지 않음 |
| 공동 경계 배치 | 원본 선의 경로와 이동한 경계 양쪽의 채움 | 확정 특징·명시 채움·기하 내부를 덮지 않음; 다른 재질을 가로질러 색을 가져오지 않음 |
| 저장 전 대조 | 실제 선·면·특징, 변경 영역과 원본 대비 손실 | 수치 통과로 시각 결함을 승인하지 않음 |

재질색 검사와 기하 보호를 분리한다. 같은 재질의 관찰 조각이 나뉘어도 허용색 검사에서 빠지지 않지만, 이것만으로 별개 물체를 하나의 연결 면으로 합치지 않는다. 선 배치가 조각 경계의 칸을 선/배경으로 이동시킨 경우 실행된 공동 경계 배정과 일치하는지 검사하고 `boundaryTransfers`로 기록한다. 이 기록은 원본 형태 보존의 시각 승인이나 명시 채움 침범 허가가 아니다. 실제 선 검사 후에도 원안 대비 면·틈이 줄었는지 확인한다.

저장된 native와 확대 PNG를 다시 열어 팔레트·격자·재현을 검사하고, 2단계의 필수 경계 목록으로 실제 누락·폭·틈·얼굴을 재검수한다. 용량 시험 통과는 최종 배치 성공 보증이 아니다.

## 6. 확인된 디테일 손실 수정

확인된 손실만 승인된 공용 처리로 수정한다. 목적지 도트 덧칠, 캐릭터 이름별 분기, 안 맞는 보정 연쇄는 금지한다. 수정 밖을 비교한다. 필요한 공간 자체가 부족하면 보정을 붙이지 않고 2단계로 돌아가 선정·설계·배치부터 다시 진행한다. 이미 정한 사용자 자산 크기를 바꿔야 하는 경우에는 변경 근거를 제시하고 사용자 결정을 따른다.

## 7. 격자 초안 확정·저장 검수

원본·캐릭터화본·설계 원안·실제 격자 초안을 전신 및 정수 확대에서 비교한다. 눈/피부/코/입/손/의상/외곽선은 각각 판단한다. 원안→격자 초안의 변화와 격자 초안→저장본의 보존은 다른 검사다. 생성 원안을 뒤에서 격자 초안으로 이름만 바꾸거나, 결함을 가진 초안을 그대로 보존했다는 이유로 통과시키지 않는다.

잠금 전에는 SKILL.md의 **제1규칙**을 적용한다. 다음은 필수 비교 축이며 색의 존재 검사로 대체하지 않는다.

| 항목 | 비교할 형태와 관계 | 실패 사례 |
| --- | --- | --- |
| 눈 | 실제 원본 대비 각 눈의 가로·세로·상부 형태·기울기, 위쪽 획의 접촉/근접/분리, 존재하는 내부 면의 비율·위치, 양쪽 눈 관계·시선 | 눈 잠식, 세로 타원의 원형화, 원본에 없는 흰 간격 강제, 내부 면의 막대/점화, 크기 불균형·시선 변경 |
| 코·입·피부 | 코의 밝음·음영 관계, 입의 연결·방향과 표정, 피부 기본 면과 음영 위치 | 코·입 누락, 원하지 않은 표정 변경, 피부 면 감소·얼룩·재질색 혼입 |
| 손·소품 | 엄지와 감긴 손가락의 면, 굽힘, 손가락 연결·틈, 손과 물체의 앞뒤·접촉 | 색 몇 칸만 남고 쥐는 형태가 달라짐, 정상 하이라이트가 구멍이 됨 |
| 팔다리·가림 | 어깨/골반에서 관절·손발까지의 연결 면, 앞의 장식과 뒤의 신체 관계 | 손만 남고 팔이 잘려 보임, 관절의 어두운 면을 선으로 축소하거나 갑옷색으로 대체 |
| 외곽선·재질 경계 | 실제 선 폭·연속성·계단 흐름, 접합부, 선 양쪽의 면과 빈 공간 | 기존 선과 중복, 누락, 돌출, 면이나 틈을 먹어 연결, 머리·눈 경계 병합 |

검수 순서는 **반대 증거 탐색 → 원본의 의도된 형태인지 대조 → 항목별 판정**이다. 필수 항목마다 관찰한 차이, 사전 기준, 판정 이유, 정확한 비교 PNG/부위를 기록한다. ‘눈이 보임’처럼 존재만 적거나 여러 항목에 같은 문구를 넣은 기록은 검수 근거가 아니다. 이상 여부가 불명확하면 UNVERIFIED로 두고 추가 관찰하며, 결함을 확인하면 FAIL로 둔다. 수정 후 같은 부위와 영향받는 인접 부위를 재검수한다.

3단계의 새 원안이 2단계 용량 시험과 달라졌다면 실제 5단계 배치에서 위 형태가 유지되는지 다시 확인한다. 새 원안이 격자에 맞지 않으면 2·3단계로 돌아간다. 현재 사용자 고정 조건을 임의 변경하거나 눈만 더 작은 격자를 사용하지 않는다.

`prepare`가 만든 native/정수 확대 PNG를 실제로 검수한 뒤 `lock`으로 확정한다. 잠금 전 전체 변환 재현과 실제 선 검사를 수행하며, 누락·폭·형태 손실이 남으면 잠글 수 없다. `finalize`와 `verify`는 잠긴 PNG 및 검사 근거만 읽는다. 선 추출·가늘게 만들기·재배치·리사이즈는 호출하지 않는다. 최종 PNG를 다시 읽어 native 도트 배열과 확대본이 잠긴 초안과 완전히 같은지 검사한다. 변경이 필요하면 새 실행에서 초안부터 다시 검수한다. 기술 통과·시각 검수·사용자 채택은 별개다.

## 실행 기록·차단

`prepare`는 색 배정·면 배치·필수 선·눈·외곽선의 실제 중간 PNG와 입력 해시를 `diagnostics/trace.json`에 연결한다. 변환이 중단되어도 완료된 단계는 남긴다. 최초 손실 단계는 이 이미지들을 같은 좌표·배율로 비교해 찾는다. 진단 출력은 검수 승인이나 납품 파일이 아니다.

배경 배정은 캔버스 바깥 연결 영역뿐 아니라 머리카락·팔다리 사이의 닫힌 빈 공간도 원본에서 확인한다. 명시적으로 배정된 배경을 RGB 차이만으로 전경으로 되돌리지 않는다. 내부 선은 관찰한 잉크만 색 배정에서 제외하며, 주변 면은 원래 재질 팔레트를 따른다. 선 주변이 한 재질로 확인된 경우에만 그 재질색으로 빈자리를 채운다.

눈과 입은 보호 영역이라는 이유로 선 검사를 생략하지 않는다. 눈의 선·면·반사광 역할을 원본에서 구분하고, 선 경로를 같은 격자에 예약한 다음 남은 공간에 면을 배치한다. 원본에서 닫힌 테두리만 닫힌 경로로 취급한다. 입선도 원본 경로로 배치하며, 눈·입·일반 외곽선의 격자 소유권 충돌은 차단한다. 저장 PNG의 누락 선과 잉여 잉크를 다시 검사하고, 생성 원안에서 이미 달라진 표정은 변환 성공으로 승인하지 않는다.

필수 열린 내부 곡선은 원본에서 확인한 양끝·봉우리·굽힘의 순서와 굽힘 폭을 함께 배치한다. 골격의 모든 끝점을 보호하지 않는다. 관찰 창 안의 원본 선에서 후보를 구하고, 봉우리/굽힘 높이와 바닥 폭을 유지하며 가지·자기 접촉·2×2 뭉침 없는 한 줄을 선택한다. 선을 비운 자리는 관찰한 인접 재질색으로만 채운다. 공간이 부족하거나 관찰이 모호하면 차단한다. 탐색 한도 도달은 표현 불가능의 증명이 아니다. 관찰 입력 변경 시 4단계부터 다시 실행하며 기존 잠금이나 검수 승인을 재사용하지 않는다.

새 제작은 `stageChecks.version: 3`의 7개 독립 레코드다.

`characterization → pixel-capacity → pixel-design → material-assignment → grid-placement → detail-repair → visual-verification`

1단계는 canvas와 execution을, 2단계는 native/cell/origin을 잠근다. 3단계는 설계 원안이다. 4단계 input/output은 같은 원안이며 `executionOptions`와 `assignment:{plan,map}`를 갖는다. plan/map은 절대 경로와 SHA256 파일 증거다. 4단계 검사항목은 regionSeparation, boundaryConflicts, materialOwnership, allowedColors, featureExceptions, boundaryOwnership, ambiguity, comparison이다. 원본 구분 이미지가 실행 배정표에서 다시 생성한 이미지와 다르면 차단한다.

5단계부터 배정표, 격자, 팔레트, 선 정책을 바꾸지 않는다. 6단계는 modified/unchanged를 기록하고, 7단계는 이미지를 수정할 수 없다. 입력 변경 시 해당 단계부터 재실행한다.

검수 기록의 `gridDraft`는 실제 native/확대 PNG와 격자를 결속하고, `sourceComparison`과 `visual` 관찰을 각각 요구한다. `locked-draft/lock.json`은 검수·실행·PNG 해시와 디코딩 도트 배열 해시를 고정한다. 잠금 누락, 변경된 검수/코드/입력, 한 도트 변경은 내보내기를 차단한다.

2단계 selection의 기존 실제 후보/마스크/경계/표현력 증거 형식은 유지한다. 모든 필수 경계는 coverage,width,continuity,flow,clearance를 별도로 관찰한다. 고정 격자·팔레트 확인과 미학적 판단은 별개다.

`stage-gates.cjs`의 `assertProductionStages`가 새 7단계를 요구한다. `assertStages`는 version1/2 과거 기록 조사에도 쓸 수 있지만 새 납품 허가는 아니다. 구분 이미지는 검수용이며 최종 아트가 아니다.
